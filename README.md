## About me

I'm Princestan Uwoh. I'm doing a **Master's in Cybersecurity at Queensland University of Technology (QUT)** and I have a BSc in Computer Science. I'm moving from software development into application security and governance, risk and compliance (GRC), and I learn best by working on a real system.

- **Building MyIdento.** [MyIdento](https://myidento.com) is a digital business card and NFC card platform for individuals and teams. I build and run it end to end: a React frontend and a FastAPI backend with PostgreSQL, Redis and Celery, using Clerk for identity and Stripe, Paystack and Flutterwave for billing.
- **Cybersecurity.** I apply what I study to my own product: authentication and authorisation, multi-tenant access control, webhook and payment verification, secure file handling, and audit logging. I write up what I learn in [security-journal](https://github.com/Blaziod/security-journal).
- **Coursework.** Machine learning is one of my university courses. It is not my focus right now.
