## About me

I'm Princestan Uwoh, a developer with a BSc in Computer Science. I started in frontend work (React, React Native, Vite) and now spend my time on three things:

- **Machine learning.** Building and fine-tuning models with PyTorch, scikit-learn and Hugging Face. My latest work is in [IFN580-A2](https://github.com/Blaziod/IFN580-A2): clustering, BERT attention analysis and a fine-tuned Qwen question answering model.
- **Application security and GRC.** I keep a public learning log in [security-journal](https://github.com/Blaziod/security-journal) and build and run [MyIdento](https://myidento.com), a multi-tenant identity platform.
- **Studying.** I'm currently doing my Master's degree at **Queensland University of Technology (QUT)**.
